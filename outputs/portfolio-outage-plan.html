Fix Sequence

Normalize after cache read

Wrap cached(locale) and cached(slug, locale) results so createdAt, updatedAt, and publishedAt are real dates before UI code sees them.

Harden render points

Add a tiny helper so invalid dates fall back to a valid created/published date instead of throwing.
